# Чем строим и что нельзя

Читать перед тем, как добавить библиотеку, плагин, скилл, сервис или скрипт. Чего нет в списке
«Можно», то добавляется только с согласия Олега, с записью сюда.

## Можно

| Слой | Чем | Почему так |
|---|---|---|
| Сайт и страницы | Статичный HTML, CSS и JS без сборки, GitHub Pages | Бесплатно, без пайплайна, правится из любой сессии |
| Анимации | Библиотека Motion (vanilla, `motion` с jsdelivr, версия закреплена в ссылке) | Работает без React и сборки |
| Шрифты | Google Fonts: Unbounded + Golos Text | Кириллица, уже на сайте |
| Бот, API, заявки | Supabase Edge Functions (Deno, TypeScript), PostgreSQL | Уже работает; бесплатный тариф |
| Разделение бизнесов и роли | `business_id` во всех таблицах + Row Level Security в Postgres | Права проверяет база, а не только интерфейс |
| Telegram | Bot API, Mini App (Telegram WebApp JS) | Главный канал клиентов |
| Оплаты | Ссылки monobank и эквайринг самого бизнеса | Деньги клиентов бизнеса не идут через нас |
| AI-менеджер, голос | API модели через Edge Function, ключ в секретах Supabase | Ключ никогда не попадает в браузер и репозиторий |
| Статус работы | `node scripts/roadmap.mjs` | Без зависимостей |
| Проверка | Скилл `verify-zapys`, скриншоты страниц | Проверяем путь человека, а не ответ 200 |

## Скиллы и плагины

| Что | Где | Правило |
|---|---|---|
| `zapys-mode`, `verify-zapys`, `unslop`, `principle-*` | `.claude/skills/` в репозитории | Основа, грузятся по AGENTS.md |
| `frontend-design` (Anthropic) | скилл аккаунта | Загрузить перед любой UI-задачей |
| impeccable (pbakaus), ui-ux-pro-max | сторонние | Только после чтения SKILL.md целиком, копией в `.claude/skills/` с указанием коммита источника, с согласия Олега |
| Mobbin | коннектор в чате | Референсы экранов, в код не копируем |

## Референсы для дизайна

- **DesignBookmark Motion**: https://designbookmark.com/motion. Живые анимированные компоненты
  с кнопками «Copy for Claude» и «Copy code»; часть взята из Kokonut UI и SmoothUI.
  Как использовать: скопировать промпт компонента и дописать к нему
  «без React и сборки, vanilla JS, анимации через `motion` из CDN, токены и шрифты сайта Avenue».
  Перед вставкой открыть страницу источника, проверить лицензию и записать компонент в
  `THIRD-PARTY-NOTICES.md`. Лицензия неясна, значит берём идею, а не код.
- 21st.dev, Magic UI, cult-ui: React-компоненты, берём идею и CSS, не зависимости.
- Чек-лист против AI-шаблона: `docs/plans/2026-11-16-business-os.md`, раздел 4.

## Нельзя

- Платное: Motion+, платные API, домены, подписки, реклама. Сначала выручка и строка в листе «Капитал».
- GitHub Actions и любые CI без явного согласия Олега.
- Сборка сайта (React, Next, Vite, Tailwind CLI) и npm-зависимости на страницах.
- Ключи, токены и пароли в репозитории: он публичный. Только секреты Supabase.
- Сторонние трекеры и аналитика с cookies без согласия посетителя.
- Реальные данные клиентов в тестах и демо: только синтетические записи с пометкой, удаляем за собой.
- Деплой функций и миграций в production: готовим в ветке, деплоит Олег.
- Прямые коммиты в `main`: только ветка и pull request.
- Хранение медицинских данных (диагнозы, противопоказания) сверх анкеты, которую видит только специалист.
- Код без лицензии или с несовместимой лицензией; чужой компонент без записи в `THIRD-PARTY-NOTICES.md`.
- Отправка сообщений лидам и клиентам от имени Олега: только черновики.
