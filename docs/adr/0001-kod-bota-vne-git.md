# ADR 0001. Код бота живёт вне git, и это надо закрыть

Дата: 15 ноября 2026. Статус: принято, работа не начата.

## Что обнаружено

Боевой код Zapys лежит в Supabase Edge Functions и ни в одном репозитории не хранится.
У `zapys-bot` на момент записи третья версия деплоя, у `zapys-lead` вторая, у `zapys-api` первая.

Из этого следует:

- Истории изменений нет. Что именно изменилось между версией 2 и версией 3 бота, узнать нельзя.
- Откатиться нечем. Если деплой ломает запись, предыдущий код не восстановить.
- Ревью нет. Правка попадает в продукт сразу, минуя diff и pull request.
- Агенту нельзя доверить правку бота: он не сможет ни сравнить, ни вернуть.

При этом продукт продаётся за 3 900 грн с поддержкой 490 грн в месяц. Обещание на сайте —
бот работает 24/7. Один неудачный деплой без возможности откатиться нарушает это обещание
у всех клиентов сразу.

## Почему так вышло

Edge Functions деплоятся из интерфейса Supabase одним действием. Это быстрее, чем держать
репозиторий, и на этапе прототипа такой выбор оправдан: продукт менялся каждый день, а истории
никто не читал. Цена этого решения появляется в тот момент, когда у продукта возникают платящие
клиенты, то есть прямо сейчас.

## Решение

Git становится источником истины для кода функций. Supabase остаётся средой исполнения.

Порядок работы с ботом после этого ADR:

1. Текущий боевой код каждой функции снимается и кладётся в репозиторий как есть, отдельным
   коммитом «зеркало», без правок. Это точка отсчёта.
2. Любая правка делается в ветке и проходит через pull request.
3. Деплой выполняет Олег вручную из интерфейса Supabase после слияния. Агент готовит правку и
   пишет в описании PR, какую функцию предстоит задеплоить.
4. После деплоя прогоняется `verify-zapys`, чтобы убедиться, что путь клиента целый.

## Где хранить

Код бота не должен попасть в публичный репозиторий. `zapys-ua.github.io` публичный, потому что это
сайт на GitHub Pages. Серверная логика продаваемого продукта там лежать не должна.

Поэтому зеркало функций живёт в отдельном приватном репозитории. Этот репозиторий остаётся сайтом
и инженерным слоем: правила, скиллы, документы, проверка.

## Что это стоит

Один вечер на зеркалирование трёх функций и настройку порядка. Дальше каждая правка бота дороже на
один pull request. Взамен появляется откат, diff и возможность отдать правку агенту.

## Чего решение не делает

Не добавляет CI и GitHub Actions: лимиты расходуются быстро, и проверка пока запускается вручную
через `verify-zapys`. Не автоматизирует деплой: право задеплоить остаётся у Олега.
