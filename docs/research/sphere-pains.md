# Боли бизнеса по сферам и будущие продукты Avenue

Живой документ. Обновляет еженедельный совет (исследователь рынка): новые боли с источником,
пересчёт ICE, решение по каждому продукту. Из таблицы «Лабораторія» берутся карточки для блока
«Лабораторія Avenue» на главной (массив `LAB` в `index.html`). Голоса «Хочу першим» приходят в
`zapys_leads` полем `niche`.

Правило: продукт без источника боли не попадает на сайт. Строим, когда набралось 5 голосов за
месяц или 3 бизнеса попросили сами.
