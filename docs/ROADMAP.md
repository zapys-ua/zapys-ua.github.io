# Дорожная карта Avenue для бизнеса

Единственный источник правды о том, на каком мы этапе. Читает Claude Code в начале каждой сессии,
обновляет в конце. Статус одной командой: `node scripts/roadmap.mjs`.

Бренд для клиента: **Avenue**. Zapys остаётся модулем «Запис» и именем репозитория.
Стратегия и цены: [план Avenue для бизнеса](https://claude.ai/artifact/KNNK7WidoCB4eCuMwtKXss).
План компании на месяц: [Avenue: план развития на месяц](https://claude.ai/artifact/25znmgFsX5W3QVPX2PMrT1).
Каталог услуг и подход к дизайну: `docs/plans/2026-11-16-business-os.md`.

## Как вести этот файл

- Задача закрыта, когда выполнено «Готово, когда». Отметка: `- [x] **1.2** ... (2026-11-18, PR #4)`.
- Задачу не отмечаем по факту написанного кода: только по проверенному результату.
- Новая задача получает следующий номер внутри этапа. Номера не переиспользуем.
- Этап закрыт, когда закрыты все задачи и пройдены ворота. Следующий этап до этого не начинаем,
  кроме задач с пометкой «можно параллельно».
- В конце сессии одна строка в `docs/progress-log.md`: дата, что закрыто, что дальше.
- Модель указана для каждой задачи. Расход: Н низкий, С средний, В высокий.

### Агент ставит задачи сам

- Блокирует деньги или текущий этап (ошибка в записи, дыра в доверии, обещание сайта не работает):
  сразу задачей в текущий этап, следующим номером, с пометкой «добавил агент: причина».
- Всё остальное: строкой в «Бэклог» внизу файла. Формат:
  `- [ ] **Б7** Что сделать. Источник: наблюдение / persona-review / лид / клиент / конкурент. ICE 8/6/7`,
  где I влияние на деньги или удержание, C уверенность, E лёгкость, каждое от 1 до 10.
- Просьба платящего клиента получает +2 к влиянию. Идея без источника не записывается.
- В бэклоге не больше 15 строк: новая вытесняет худшую по ICE.
- По воскресеньям: 1-3 лучших по ICE переходят в ближайший этап, устаревшие удаляются.
