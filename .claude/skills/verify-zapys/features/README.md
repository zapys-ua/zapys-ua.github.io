## Порядок, в котором стоит описывать остальные

Карта заполняется по мере проверки, а не заранее заглушками. Два файла уже есть как образец
структуры. Следующие по важности для денег: три входа с одним графиком, панель владельца,
партнёрская метка. Функции, у которых таблицы пустые, — сертификаты и лист ожидания — описываются
вместе с выяснением, реализованы ли они вообще.

## Чем описание функции отличается от обещания

Обещание отвечает на вопрос «что продаём». Описание функции отвечает на четыре других: из чего она
состоит, как до неё добирается человек, как её прогнать проверкой и где она ломается. Четыре
заголовка в файлах карты именно про это.

## Правило честности

Если проверка нашла расхождение между сайтом и продуктом, расхождение идёт в раздел «Где ломается»
соответствующего файла, а сценарий не ослабляется, чтобы он прошёл. Обещание на сайте читает
будущий клиент, поэтому расхождение — это дефект продукта, а не дефект проверки.
