## Запланированная задача

Совет запускает облачная задача «Avenue — совет экспертов недели» по воскресеньям в 13:23 по Киеву
(Sonnet 5.5). С 22.11.2026 в ней два постоянных эксперта сверх прежних:

- **Арт-директор витрины.** Сравнивает главную с 2-3 свежими работами Awwwards или Godly и сам
  делает 1-2 улучшения отдельным PR из ветки `site/<год>-W<неделя>`. Правила: vanilla JS, анимации
  только transform и opacity, reduced motion, скриншоты 390 и 1440, `node scripts/check-prices.mjs`.
- **Стратег бизнес-модели.** Проверяет сигналы спроса по слоям `docs/plans/2026-11-22-business-model-v2.md`
  (заявки с интересом Avenue Club, Avenue Gifts, Оплата за результат) и решает: строить, ждать или
  убрать с витрины.

Итог совета одним PR из `council/<год>-W<неделя>`, ничего не мержится без Олега.
